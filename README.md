# 📊 Real-Time Job Market Insights Dashboard
SQL + Power BI project analyzing job market trends, skills demand, and hiring patterns

## 🔍 Project Overview
This project analyzes job market data to identify hiring trends, in-demand skills, and regional patterns using SQL and Power BI. The goal is to transform raw data into actionable insights for job seekers and businesses.

---

## 🎯 Objectives
- Analyze job demand across regions and roles  
- Identify top skills required in the market  
- Track hiring trends over time  
- Build an interactive dashboard for insights  

---

## 🛠️ Tools & Technologies
- SQL (MySQL)  
- Power BI  
- CSV / Excel  

---

## 📂 Dataset
- 10,000+ job records  
- Multiple tables (jobs, company, location, skills)  
- Covers different roles, locations, and experience levels  

---

## ⚙️ Project Workflow

### 1. Data Preparation
- Created relational database schema  
- Cleaned and validated data  
- Handled missing values and duplicates  

### 2. Data Analysis (SQL)
- Job trends by month and year  
- Jobs by location and company  
- Salary analysis by role and experience  
- Skills demand analysis  

### 3. Dashboard Development (Power BI)
- Built interactive dashboards  
- Added slicers (role, location, skills, experience)  
- Created KPIs and dynamic visuals  

---

## 📊 Key Insights
- Bangalore has the highest job demand  
- Mid-Senior level roles dominate the market  
- Power BI, AWS, and Python are top in-demand skills  
- Salary trends vary significantly by role and experience  
- Hiring trends fluctuate across months  

---

## 📈 Business Impact
- Helps job seekers focus on high-demand skills  
- Enables companies to understand hiring trends  
- Supports data-driven career decisions
